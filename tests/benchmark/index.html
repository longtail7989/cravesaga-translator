Translation cache benchmark

Sequential 200, 500, 700 decimal MB synthetic datasets. Each uses a separate owned temporary database, deleted before the next dataset. No providers, credentials, network, or production cache access.

Logical bytes mean the sum of UTF-8 JSON bytes of normalized cache entries (source, translation, ID, context, language, timestamps). Storage estimate deltas are approximate origin-wide browser usage, not exact physical database size. Native quota/disk failures are not performance failures.
