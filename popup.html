ChatGPT 계정 연결

아직 연결 상태를 확인하지 않았습니다.

로컬 도우미를 통해 공식 ChatGPT 페이지에서 직접 로그인·승인합니다. 이 확장에 비밀번호·인증 코드·토큰을 입력하지 마세요. 로그인은 번역·모델 호출이나 설정 저장을 하지 않습니다. 팝업을 닫아도 로그인은 계속됩니다.

연결 후 모델을 조회하고 ‘변경 사항 저장’을 눌러야 이 제공자를 사용합니다. 연결 상태는 특정 모델의 이용 자격·사용량 잔여를 보장하지 않습니다.

이 확장의 설정에 저장하며 게임 페이지에는 전달하지 않습니다.

제공자 상태 · 연결 및 비용 안내

저장된 제공자 설정을 불러오는 중입니다.

OpenAI·Anthropic·Gemini API는 별도 API 인증·과금으로 연결합니다. ChatGPT 구독 연결은 로컬 도우미와 공식 승인 절차를 사용하며, 제공자의 모델·사용량 한도가 적용됩니다. AI 모드 저장·모델 조회·테스트는 서버 접근 권한을 요청할 수 있습니다. 권한 창에서 팝업이 닫히면 다시 열어 저장 상태를 확인하세요.

오래된 번역 정리
마지막 번역 저장 시각이 오래된 순서로 지정한 개수만 삭제합니다. 자동 삭제는 하지 않습니다. 현재 화면에 이미 표시된 번역은 유지되며 즉시 다시 번역하지 않습니다.
캐시 삭제 후에는 같은 문구가 다시 전송될 수 있습니다. 기록 초기화는 실제 요금·사용량을 취소하지 않습니다.

        
캐시 파일 가져오기 · 내보내기
캐시 파일 관리
대용량은 NDJSON v3(첫 줄 형식 정보 · 항목당 한 줄 · 마지막 줄 종료/개수)로 순차 처리합니다. 기존 JSON v1/v2/v3는 32 MiB 이하만 지원합니다. 서버 권한 없이 기기 안에서 처리합니다.
작업 중 팝업을 닫으면 중단될 수 있음. 완료 안내가 나올 때까지 열어 두세요. 저장 창에서 팝업이 닫히면 작업을 다시 시작해야 합니다.
원문과 대상 언어가 같으면 중복입니다. 선택한 쪽을 수동 수정 여부보다 우선합니다. 파일에만 있는 새 항목은 두 방식 모두 추가합니다. 이 선택은 가져오기 실행 시 적용되며, 제공자 설정 저장과는 별개입니다.
캐시 개인정보·호환성 안내
파일에 게임·스토리 원문과 번역문이 포함됩니다. 개인정보·저작권에 유의해 비공개로 보관하고 무단 공유하지 마세요. API 키·브리지 토큰·서버 주소는 포함하지 않습니다.
대상 언어와 정확히 일치하는 원문만으로 번역을 재사용합니다. 화면·문맥·제공자·모델이 달라도 재사용하며, 빠른 메모리 캐시는 최근 항목만 제한적으로 유지합니다. 병합 시 중복 번역은 선택한 쪽을 그대로 사용합니다. 로컬 유지가 기본이며, 파일 우선은 기존 수동 수정도 덮어쓸 수 있어 실행 전에 다시 확인합니다. 같은 파일 내부의 중복은 기존 수동 수정·저장 시각 우선 규칙으로 한 항목을 정합니다. 전체 교체는 파일 검증이 끝난 뒤 한 번에 반영하며 실행 전에 다시 확인합니다.
원문이 없는 v0.1 기록은 새 형식으로 승격되기 전까지 내보내기에서 제외됩니다. 시작 시 저장 개수와 실제 내보낸 개수는 다를 수 있습니다. 브라우저의 저장소 할당량과 기기 여유 공간 등 실제 저장 한도는 계속 적용됩니다. 가져오기 실패 시 기존 캐시는 유지됩니다.

전송량 제한
사용량 한도
하루 글자·요청 한도는 각각 0이면 제한하지 않습니다. 기기에서 측정하는 전송량 제한이며 금액 상한이 아닙니다. 제공자 측 사용 한도와 실제 과금은 그대로 적용됩니다.

        
응답 대기와 자동 재시도
요청 시간 제한과 재시도
기본 180초 · 30~240초. 시간이 지나면 응답 지연으로 처리합니다.
0은 횟수 제한 없음, 1~20은 최초 요청 이후 최대 재시도 횟수입니다. 재시도 사이에는 점차 긴 대기 시간을 두며, 인증·접근 권한 등 재시도할 수 없는 오류는 중단합니다.
자동·수동 재시도는 추가 비용 또는 구독 사용량을 발생시킬 수 있습니다. 번역을 일시정지하거나 설정을 변경해 저장하면 대기 중인 요청과 재시도를 취소합니다. 제공자에서 이미 처리한 요청의 과금은 취소되지 않을 수 있습니다.

        
번역 범위와 보안
스토리·프로필·버튼 등 게임 엔진에서 추출 가능한 텍스트만 번역합니다. 이미지 OCR은 지원하지 않으며 모든 문구의 추출·번역을 보장하지 않습니다. 내장 번역 사전은 포함하지 않습니다.
인증값은 게임 페이지에 노출하지 마세요. ChatGPT 로컬 도우미의 설치·보안 안내는 README를 확인하세요.

      

      

        
저장된 번역 검색 · 수정 · 삭제

          
AI 호출·서버 권한 요청 없이 기기 안에서만 검색하고 저장합니다. 수동 수정은 자동 번역보다 우선하며 자동 번역이 덮어쓰지 않습니다. 오래된 번역 삭제·캐시 비우기·파일 전체 교체로는 삭제될 수 있습니다.

          

          

          
포함 검색은 최대 256자, 정확한 원문은 최대 8,192자입니다. 큰 캐시는 나누어 확인합니다. 한 페이지에 최대 20개만 표시합니다. 탭을 열어도 자동 검색하지 않습니다.
